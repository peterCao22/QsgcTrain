# 优化计划 v2.0 — feature/optimization-v2

> 基于两次全量 Top-50 人工验证（91只样本）及周K线数据统计分析  
> 分支：`feature/optimization-v2`  
> 计划创建：2026-02-27

---

## 一、目标

在当前 v1.0 基础（AUC=0.7618，Precision@10=90%，21期平均超额+1.33%）上，通过增加周线特征、板块/概念热度特征、大市值过滤和筹码信号优化，使模型在以下维度获得提升：

| 指标 | 当前 v1.0 | 目标 v2.0 |
|------|:---:|:---:|
| Top-20 平均超额（好行情）| +6.89% | **>+10%** |
| Top-20 平均超额（差行情）| +1.72% | **>+4%** |
| 大牛股（涨幅>20%）命中数 | 平均 5/50 | **>7/50** |
| 大跌股（跌幅>10%）混入数 | 差行情约10只/Top20 | **<5只/Top20** |

---

## 二、任务清单（按优先级）

### P0 — 低成本高收益，优先实现

#### T1：大市值 + 稳定行业过滤
- **问题**：格力(2106亿)、京沪高铁(2397亿)、中国移动(2万亿)、银行、高速公路等稳定型股票频繁混入Top50，稀释了有效名额
- **方案**：在 `daily_scan.py` 扫描输出阶段，增加后置过滤规则：
  - 市值上限：`float_cap < 500亿`（流通市值）
  - 行业黑名单：银行、高速公路、水务、电力（稳定行业代码列表）
- **文件**：`scripts/daily_scan.py`
- **预期**：每次扫描去除 3~5 只无效票，Top-20 质量提升明显

#### T2：周线量能比特征 `weekly_vol_ratio`
- **问题**：好行情中该指标与涨幅相关系数 +0.35，是所有指标最强，但模型完全缺失
- **方案**：在 `features/` 新增 `weekly.py` 模块，计算：
  - `weekly_vol_ratio`：近4周均量 / 近13周均量（量能加速趋势）
  - `weekly_vol_spike`：最近1周量 / 近8周均量（本周是否放量）
- **文件**：新建 `features/weekly.py`，修改 `features/builder.py`
- **预期**：大牛股（涨幅>20%）在好行情下排名提升5~10位

#### T3：周线价格分位特征 `weekly_price_pct`（高位惩罚）
- **问题**：差行情中19只跌幅>10%的股票，26周价格分位均值高达90.4%；该指标可作为高位惩罚因子
- **方案**：
  - `weekly_price_pct_26w`：当前收盘在近26周价格区间的百分位（0~1）
  - `weekly_price_pct_52w`：当前收盘在近52周价格区间的百分位
- **文件**：`features/weekly.py`，`features/builder.py`
- **预期**：差行情大跌股混入数减少约50%

---

### P1 — 中优先级，有一定开发量

#### T4：板块/概念热度特征
- **问题**：两次扫描中涨幅最好的股票（商业航天/人形机器人）均属于当期最强主题，但模型对概念热度无感知
- **方案**：
  - `concept_ret_20d`：该股所属概念板块近20日涨幅（取概念等权平均）
  - `concept_ret_rank`：该概念近20日涨幅在所有概念中的排名分位（0~1，越高越热）
  - `concept_mf_5d`：该概念板块近5日资金净流入（用 `moneyflow` 表聚合）
  - 数据来源：`kline_all` 聚合概念板块收益 + `moneyflow` 聚合概念资金流
- **文件**：`features/sector.py` 扩展 或 新建 `features/concept.py`
- **前置条件**：需要确认数据库中是否有概念-股票映射表（`sector_member` 或类似）
- **预期**：捕捉主题行情，大牛股排名从21~30提升到11~20

#### T5：W底形态识别优化
- **问题**：当前W底算法（低点差<15%）漏识别率约50%，300629/301050/300992均被漏掉
- **方案**：
  - 低点差阈值放宽至 25%
  - W底搜索窗口从20周扩展到26周
  - 新增"V底"识别（单次深跌后快速反弹，无需双底）
  - 新增"箱体突破"识别（横盘N周后向上突破）
- **文件**：`features/weekly.py`
- **预期**：W底识别率从50%提升到75%+

#### T6：筹码特征优化
- **问题**：`筹码分散`在有/无概念热度背景下信号方向相反；`价格刚突破平均成本`是重要买入窗口
- **方案**：
  - 新增 `chip_vs_avg_cost`：(close - chip_avg_cost) / chip_avg_cost，衡量价格相对平均成本的位置
    - 接近0（刚突破成本）= 买入窗口
    - 大幅高于0（远超成本）= 高位风险
  - 调整 `chip_concentration` 的特征描述方向（概念热时低集中度是正面信号）
- **文件**：`features/chip.py`，`features/builder.py`

---

### P2 — 中长期优化，需较多时间

#### T7：市场环境状态特征
- **问题**：好行情和差行情下，各特征的有效方向完全不同（如多头排列在差行情是负面信号）
- **方案**：
  - 新增 `market_trend_20d`：指数近20日涨幅（已有 `index_bar1d`）
  - 新增 `market_vol_20d`：市场近20日波动率
  - 新增 `market_breadth_5d`：近5日上涨股票数 / 总股票数（市场宽度）
  - 这些特征让模型自动学习"不同环境下各信号的权重应该不同"
- **文件**：新建 `features/market_env.py`，`features/builder.py`

#### T8：`相对走弱60` 特征重审
- **问题**：差行情中有26只"相对走弱60"的股票，平均涨幅 -5.24%，是最大噪音源
- **方案**：分析该特征在好/差行情中的双向表现，考虑：
  - 与市场状态特征交互（差行情时降权）
  - 或直接替换为更精准的"60日相对强弱"区间特征

#### T9：重新训练并回测验证
- **触发条件**：T1~T3 实现后即可触发第一轮重训
- **验证方式**：对 2024-2025 年多个历史日期批量扫描，与 v1.0 结果对比

## 五、验证标准

每个阶段重训后，必须通过以下验证才算合格：

1. **AUC ≥ 0.76**（不低于 v1.0）
2. **好行情回测 Top-20 超额 ≥ +8%**（当前 +6.89%）
3. **差行情回测 Top-20 超额 ≥ +3%**（当前 +1.72%）
4. **至少3个历史日期验证，结果一致**（避免过拟合单日）
5. **大牛股（涨幅>20%）平均排名进入 Top-30**（当前部分在 21~41 名）
